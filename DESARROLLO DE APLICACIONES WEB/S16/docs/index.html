El sistema

Una base sólida para administrar el día a día.

El proyecto consolida los avances desarrollados durante el semestre en una aplicación con rutas protegidas, formularios validados, consultas parametrizadas y una interfaz enfocada en la toma de decisiones.

Capacidades

Acceso seguro

Registro, autenticación y cierre de sesión con contraseñas protegidas y control de acceso.

02

CRUD completo

Crear, consultar, actualizar y eliminar productos, proveedores, clientes y facturas.

03
